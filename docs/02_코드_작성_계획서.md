## 1. 기술 스택

### 1.1 백엔드

| 영역 | 선택 | 사유 |
|---|---|---|
| 언어 | Python 3.11+ | `asyncio.TaskGroup`, `StrEnum` 사용 |
| 웹 프레임워크 | **FastAPI + uvicorn** | async 네이티브. 정류장 병렬 조회와 자연스럽게 맞물림 |
| HTTP 클라이언트 | `httpx` (async) | 정류장별 도착정보 병렬 조회에 필수 |
| DB | `sqlite3` (표준 라이브러리) | 단일 파일, 조인 성능 충분, 외부 의존 없음 |
| 설정 | `pydantic-settings` + `.env` | API 키 관리, 타입 검증 |
| 응답 스키마 | `pydantic` | FastAPI와 통합. 프론트 계약 명시 |
| 데이터 구조 | `dataclasses` | 코어 로직용. ORM 불필요 |
| CLI (개발용) | `typer` | DB 구축 배치 + 디버깅 진입점 |
| 테스트 | `pytest` + `pytest-asyncio` + `httpx.ASGITransport` | |
| 포맷/린트 | `ruff` | |

### 1.2 프론트엔드

| 영역 | 선택 | 사유 |
|---|---|---|
| 프레임워크 | **없음 (Vanilla JS)** | 화면이 2개뿐. React/Vue는 빌드 파이프라인 비용만 추가 |
| 스타일 | 단일 CSS 파일 | `env(safe-area-inset-*)`, CSS 변수로 다크모드 |
| 위치 | `navigator.geolocation.getCurrentPosition` | `enableHighAccuracy: true`, timeout 5s |
| PWA | `manifest.json` + service worker | 앱 셸 캐시, 홈 화면 추가 |
| 빌드 | 없음 | 정적 파일을 FastAPI가 그대로 서빙 |

> **의도적으로 경량.** 개인용 도구 하나에 SPA 툴체인을 얹으면 유지보수가 본체보다 커진다. 프론트가 커지면 그때 Vite+Preact 정도로 승급.

### 1.3 배포 (D-9, Phase 5에서 확정)

| 방식 | 도구 |
|---|---|
| A. 집 PC + 터널 | `cloudflared tunnel` — 무료, HTTPS 자동 발급 |
| B. 클라우드 | Fly.io / Railway / Oracle Cloud 무료 티어 |

**HTTPS는 선택이 아니라 필수.** iOS Safari가 비보안 컨텍스트에서 Geolocation을 차단하므로, HTTP로는 앱이 아예 동작하지 않는다.

## 3. 핵심 데이터 모델 (`models.py`)

```python
from dataclasses import dataclass
from enum import StrEnum

class Catch(StrEnum):
    SAFE  = "SAFE"      # 여유 있음
    TIGHT = "TIGHT"     # 뛰어야 함
    MISS  = "MISS"      # 못 잡음

@dataclass(frozen=True, slots=True)
class Stop:
    stop_id: str
    ars_id: str | None
    name: str
    lat: float
    lon: float

@dataclass(frozen=True, slots=True)
class Route:
    route_id: str
    route_name: str
    route_type: str | None = None
    headway_min: float | None = None

@dataclass(frozen=True, slots=True)
class Arrival:
    """실시간 도착 1건."""
    route_id: str
    stop_id: str
    eta_min: float          # 도착까지 남은 분
    order: int              # 1차/2차 차량
    congestion: int | None = None
    is_last: bool = False
    is_estimated: bool = False   # headway로 추정한 값인지

@dataclass(frozen=True, slots=True)
class Combo:
    """직통 조합 (정적)."""
    route_id: str
    board_stop_id: str
    alight_stop_id: str
    n_stops: int

@dataclass(frozen=True, slots=True)
class Plan:
    """최종 후보 1건."""
    board: Stop
    alight: Stop
    route: Route
    walk_to_board_min: float
    walk_from_alight_min: float
    eta_min: float
    ride_min: float
    total_min: float
    margin_min: float
    catch: Catch
    score: float
    congestion: int | None = None
    is_last: bool = False
```

## 4. API 계약 (`schemas.py`)

프론트를 먼저 짜든 서버를 먼저 짜든, **이 계약을 Phase 3 시작 전에 고정**한다.

```python
class PlanItem(BaseModel):
    rank: int
    board_stop_name: str
    board_stop_ars: str | None
    board_lat: float           # 지도앱 딥링크용 [F-18]
    board_lon: float
    walk_to_board_min: int
    route_name: str
    eta_min: int
    margin_min: int
    catch: Literal["SAFE", "TIGHT", "MISS"]
    alight_stop_name: str
    walk_from_alight_min: int
    ride_min: int
    total_min: int
    arrive_at: str             # "09:14"
    congestion: int | None
    is_last: bool
    is_estimated: bool

class PlanResponse(BaseModel):
    origin_label: str          # "현재 위치" | "집"
    dest_label: str            # "회사"
    departed_at: str           # "08:41"
    generated_at: str          # ISO8601, 신선도 표시용
    items: list[PlanItem]      # 최대 5
    warning: str | None        # "지금 나가면 다 놓쳐요" 등
```

### 엔드포인트

```
GET  /api/plan?lat=&lon=&to=회사      → PlanResponse
GET  /api/plan?from=집&to=회사        → PlanResponse (GPS 폴백)
GET  /api/places                      → 즐겨찾기 목록
POST /api/places                      → 즐겨찾기 등록
POST /api/feedback                    → 실측 도보시간 기록  [F-11]
GET  /                                → PWA 셸
```

- 인증: `X-Token` 헤더 고정 토큰 1개. 프론트는 localStorage에 보관.
- 모든 시간 필드는 **정수 분**으로 내려 프론트에서 반올림 로직을 갖지 않게 한다.

> **실측으로 확정된 것** (`scripts/smoke.py`, 픽스처는 `tests/fixtures/`)
> - 인증키는 **Decoding** 방식 (`httpx params=` 에 그대로)

> - `traTime1` 은 **초 단위**. `arrmsg1` 은 사람용 문자열이라 파싱하지 않는다
> - `term` 이 배차간격(분), `congestion1` 은 1~4 이고 **0 은 미측정**
> - `direction` 은 상행/하행 코드가 아니라 **행선지 종점명 문자열**
> - stop_id 체계: `getStaionByRoute` 의 `<station>` = `getStationByPos` 의 `<stationId>`

- **완료 기준**: 네트워크 없이 "집→회사 직통 노선 목록" 출력 → **픽스처 1개 노선(146번)으로 검증됨.** 실제 집→회사 대조는 Phase 1 이후

> **§9.1 질의의 조건은 `rs2.seq > rs1.seq` 하나다.** 초안에서 `direction` 으로도
> 조인했다가 되돌렸다. `direction` 은 버스 앞 행선판이고 회차 지점에서 바뀔 뿐,
> 차량은 seq 1 → N 을 연속으로 달린다. 146번 실측에서 회차점은 종점이 아니라
> 노선 한복판(seq 67, 기점에서 18.4km)이고 seq 135 는 기점으로 되돌아온다.
> 조인을 걸면 강남역9번출구(seq 66) → 강남역1번출구(seq 70) 같은 **멀쩡한 4정거장
> 조합이 죽는다.** 후보를 빠뜨리는 것은 이 프로그램이 고치려던 문제 그 자체다.
>
> 방향 문제는 seq 비교가 이미 해결한다. 도로 양쪽 정류장은 서로 다른 stop_id 에
> 서로 다른 seq 를 가지므로 반대편에서 타면 seq 가 감소해 자동 탈락한다.

> 최선 대안보다 5분 이상 좋으면 통과시킨다. 개수 제한은 두지 않았다.
> `max_per_stop` 은 '비슷할 때 섞어라', `min_distinct_stops` 는 '항상 대안은
> 남겨라' — 역할이 다르다. 상한으로 대안을 보장하려 들면 더 빠른 버스를 숨긴다.

## 10. 주의사항 / 함정

### 코어 로직

1. **정류장 방향 구분** — 같은 이름 정류장이 도로 양쪽에 존재. `direction`과 `seq`로 반드시 구분. 놓치면 **반대 방향 버스를 추천하는 치명적 버그**가 난다.
2. **회차 노선** — 순환 노선은 같은 정류장이 한 노선에 두 번 등장 가능. 조합 탐색 시 중복이 나오면 `n_stops` 최소값만 채택.
3. **막차 처리** — `is_last`를 무시하면 심야에 잘못된 추천이 나간다. 출력에 반드시 표시.
4. **다양성 보정의 함정** — 2위가 압도적으로 좋은데 같은 정류장이라고 밀어내면 안 된다. `max_per_stop`은 **동점에 가까운 후보들 사이의 타이브레이커**로만 작동해야 하며, score 차이가 큰 경우엔 순수 정렬을 우선한다.

### 모바일 / 배포

5. **HTTPS 없으면 아무것도 안 된다** — iOS Safari는 비보안 컨텍스트에서 `navigator.geolocation`을 차단한다. 로컬 개발 시 `localhost`는 예외지만, **폰에서 IP로 접속하면 즉시 막힌다.** Phase 6 전에 이걸 모르면 하루를 날린다.
6. **iOS 위치 권한은 두 겹** — iOS 설정의 Safari 위치 권한 + 사이트별 권한. 한 번 "거부"하면 다시 묻지 않으므로, 테스트 중 실수로 거부했다면 Safari 설정에서 초기화해야 한다.
7. **PWA 홈 화면 추가는 Safari에서만** — Chrome for iOS에서는 안 된다. README에 명시.
8. **`sw.js` 캐시가 개발을 방해한다** — service worker는 개발 중 갱신을 안 먹는 대표적 원인. Phase 5 **마지막에** 붙이고, 개발 중엔 비활성 플래그를 둔다.
9. **safe-area-inset** — 노치/홈 인디케이터 영역. `viewport-fit=cover` + `env(safe-area-inset-bottom)` 미적용 시 하단 버튼이 잘린다.
10. **API 키는 절대 프론트로 내리지 않는다** — 공공 API 호출은 전부 서버에서. 클라이언트 직접 호출은 키 노출 + CORS 두 가지로 막힌다.
11. **공공데이터포털 키 인코딩** — Encoding/Decoding 두 종류가 있고 라이브러리마다 요구가 다르다. Phase 0 스모크 테스트에서 확정할 것.
12. **`.env` 커밋 금지** — `.env.example`만 저장소에.
13. **첫 실행 UX** — DB가 비어 있으면 친절한 에러("`nowbus db build`를 먼저 실행하세요")를 API 응답으로도 내려야 한다.
